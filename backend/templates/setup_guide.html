⚠ Google OAuth Setup Required

Setup client_secret.json

To connect your Gmail and Google Calendar, the backend requires your Google Cloud OAuth 2.0 Client credentials.

  1. 1

    Download client_secret.json

    In the Google Cloud Console, create an OAuth 2.0 Client ID (Web application) and download the JSON file.

  2. 2

    Save to backend/client_secret.json

    Place the downloaded file into the backend directory:

    backend/client_secret.json
  3. 3

    Add Authorized Redirect URI

    In Google Cloud Console > Credentials > Your Web Client, add this Authorized redirect URI:

    {{ redirect_uri }}
  4. 4

    Enable Gmail & Calendar APIs

    Ensure both Gmail API and Google Calendar API are enabled in your Google Cloud project.
